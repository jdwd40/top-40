# The Ridiculous Top 40 — song catalogue

**Version:** 1.0  
**Contents:** 20 fictional acts, 100 fictional songs  
**Purpose:** Seed catalogue of computer-generated rival releases for the accelerated Top 40 game.

Each `song_id` is stable. Store user-created releases separately and use this catalogue to create simulated competitor releases. The artist and title are display text; `genre` can support filters or playlist graphics. Release date, chart life, sales, momentum and debut position should be generated by the app for each release, so a catalogue entry can behave differently on another game run.

## Using the catalogue

1. Treat each row as a reusable fictional recording. Pick distinct unused `song_id` values when releasing simulated rivals; recycle an entry only when starting a new game or era.
2. Give each *release* its own generated sales curve, release day and chart history. Assign different peak strength and speed so a few songs surge briefly and others climb slowly.
3. Add user songs to the same chart calculation. Rank all current releases by sales for that simulated week, and add each week’s sales to its lifetime total.
4. Keep a generated release’s title and artist consistent throughout its run. Do not interpret these jokes as actual audio recordings, lyrics, real singles or claims about real performers.

All names and song titles here are fictional parody content written for this app. The title jokes may echo pop culture conventions; no actual recordings or lyrics are supplied.
